# ADF 4.5 features excluded from the 4.9 plugin

When porting changes from `Aperture.Nop.Plugin.Misc.AkeneoConnection` in the ADF solution, retain these exclusions. These features depend on custom ADF product properties and storefront behavior absent from this nopCommerce 4.9 plugin.

## Nursery Multi-Slug default: do not add to 4.9

The 4.5 plugin version 4.50.44 introduced **Multi-Slug enabled** in the nursery family mapping's new-product defaults. Its `NewProductMultiSlugBySkuEnabled` setting writes the ADF-only `Product.MultiSlugBySkuEnabled` property when creating nursery products. Version 4.50.45 extends the original parent-only behavior to all newly created nursery products: parents, sub-model parents, child variants and standalone products. It is opt-in and never updates existing products or products in other families.

**This feature must remain exclusive to the customized 4.5 site. Do not implement it in 4.9.** Skip its family mapping property, migration/builder column, admin model/controller/factory/view field, product-creation guard, dry-run operation and tests when bringing changes across. The shared `AkeneoProductCoreSynchronizer` files may otherwise look portable; exclude these additions explicitly.

## URL folder default

The 4.5 `NewProductUrlFolderCategoryId` setting and `AkeneoProductUrlFolderSynchronizer` write ADF's custom `Product.AdfUrlFolderCategoryId`. Exclude the field, migration, admin control, import validation and tests from 4.9 as well.
